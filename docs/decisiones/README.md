# Decisiones

Registro de **por qué**, no de **qué**. Cada entrada es una decisión que se tomó,
las alternativas que se miraron, y la prueba que la refutaría.

Una decisión que no está aquí no se ha tomado: se ha quedado en una conversación, y dentro
de seis meses es arqueología.

**Formato**: `NNN-titulo.md`, y `##` para la decisión, `###` para las partes.

- El problema, en una frase
- Opciones, con su coste de cambio
- Recomendación y motivo
- Qué lo falsaría
- Qué invariante toca

**Antes de escribir aquí, mira el índice de esta carpeta.** Re-litigar una
decisión tomada es la forma más cara de no avanzar.
